# Figures Directory

**Purpose:** Store generated plots, visualizations, and figure outputs.

**Note:** Most figures are excluded from git as they can be regenerated from scripts. Only keep important reference figures or publication-ready plots if needed.

---

## Figure Generation

Figures in this directory are typically generated by:
- Jupyter notebooks in `notebooks/`
- R scripts in `scripts/` or `vignettes/`
- Analysis scripts that produce visualizations

To regenerate all figures, run the relevant notebooks/scripts.

---

## Recommended Organization

```
figures/
├── oft_analysis/              # OFT video analysis outputs
│   ├── trajectories/          # Movement trajectory plots
│   ├── heatmaps/              # Spatial occupancy heatmaps
│   ├── behavioral_metrics/    # Velocity, distance, bout plots
│   └── calibration/           # Camera calibration visualizations
├── rna_seq/                   # RNA-seq related figures
├── chip_seq/                  # ChIP-seq related figures
└── publication/               # Publication-ready figures (keep these!)
```

---

## Naming Conventions

Use descriptive names with dates:
- `trajectory_H1705011_20260525.png`
- `heatmap_arena_combined_20260609.pdf`
- `velocity_timeseries_D2_20260525.svg`

Format recommendations:
- **PNG** for raster images (plots, heatmaps)
- **PDF/SVG** for vector graphics (publication figures)
- **High resolution:** 300 DPI for publications
